# 算术星球

一个面向小学二至四年级孩子的数学思维互动网页。二年级重点训练数列规律、凑整巧算、乘除意义和两步情景推理；三年级重点训练观察算式结构、判断运算顺序、理解生活情境；四年级进一步训练大数数感、估算、运算律巧算、多步问题建模，并通过变式题发现“变化与不变”。页面可随时切换年级，每道题都提供方向性提示和思路解释。

项目还包含独立的九宫格数独页面 `sudoku.html`，提供教学、容易、中等和困难四种模式。数独在设备本地随机生成并检查唯一解，支持触屏数字键盘、键盘方向键、逐格提示、错误解释、完成奖励和进度保存。

## 使用

直接用浏览器打开 `index.html` 即可，或在本目录运行：

```bash
python3 -m http.server 8080
```

然后访问 <http://localhost:8080>。

## 发版构建

发布前运行：

```bash
npm run build
```

构建脚本会根据 CSS 和 JavaScript 的文件内容生成短哈希，并更新 HTML 中的资源地址，例如 `styles.css?v=8f3a2c1d90`。资源内容改变时版本号也会自动改变，避免浏览器继续使用旧缓存。脚本不需要下载任何依赖。

网页不依赖网络。星星数、连续答对数和最近选择的年级保存在当前浏览器中。

每个年级提供 4 种训练方式和 3 档难度，每种训练按当前难度组成一轮 3～6 题的练习。题目与答案选项会重新打乱；完成最后一题后显示本轮总结，可以选择再练一轮或更换训练。页面会记住最近选择的年级。

答对后，页面会自动写出完整的解题步骤，并配合“画图法”展示数量关系。加减法使用拼接/拆分线段图，乘除法使用相同小组或平均分块图；混合运算的每个中间算式各有一幅对应图。情景题先列式再计算，变式题分别展示左右两式，规律题则在数字方块之间标出每次变化。

“情景推理/情景翻译/多步建模”训练同时包含“故事转算式”和“算式转故事”。二年级每个难度有 4 道精选题，三年级每个难度有 6 道，四年级每个难度有 4 道，并通过“找数量、组小队、看问题”三步提示帮助孩子理解数字在生活情景中的意义。
