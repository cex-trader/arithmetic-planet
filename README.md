# 算术星球

一个面向小学三年级孩子的混合运算互动网页。重点训练孩子观察算式结构、判断运算顺序、理解生活情境，并通过变式题发现“变化与不变”。

项目还包含独立的九宫格数独页面 `sudoku.html`，提供教学、容易、中等和困难四种模式。数独在设备本地随机生成并检查唯一解，支持触屏数字键盘、键盘方向键、逐格提示、错误解释、完成奖励和进度保存。

## 使用

直接用浏览器打开 `index.html` 即可，或在本目录运行：

```bash
python3 -m http.server 8080
```

然后访问 <http://localhost:8080>。

网页不依赖网络。星星数、连续答对数和声音设置保存在当前浏览器中。

在 iPad Safari 等支持 Web Speech API 的浏览器中，点击答案或提示后，会使用设备上的中文语音朗读反馈与解题思路。右上角扬声器按钮可以随时开启或关闭语音；不支持语音合成的浏览器会自动使用简短提示音。

每种训练按当前难度组成一轮 3～6 题的练习。题目与答案选项会重新打乱；完成最后一题后显示本轮总结，可以选择再练一轮或更换训练。

“情景翻译”训练同时包含“故事转算式”和“算式转故事”。每个难度有 6 道精选题，并通过“找数量、组小队、看问题”三步提示帮助孩子理解数字在生活情景中的意义。
